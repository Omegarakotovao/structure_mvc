# structure_mvc

### 1 Cloner le repository
```sh
git clone https://github.com/mithridatem/structure_mvc.git
cd structure_mvc
```

### 2 installer les dépendances
```sh
composer install
```

### 3 démarrer le projet
```sh
php -S 127.0.0.1:8000 -t public
```

### 4 créer un fichier .env (à la racine du projet)
```env
DATABASE_HOST=
DATABASE_PORT=3306
DATABASE_NAME=poomvc
DATABASE_USERNAME=
DATABASE_PASSWORD=
```
